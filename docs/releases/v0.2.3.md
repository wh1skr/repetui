# Repetui 0.2.3

Keep studying while notifications and media progress stay out of the way.

- Open media progress automatically for incoming files or download errors. Checks and uploads keep you on the study screen; press `s` whenever you want progress.
- Show one compact notification preview at the bottom of the pane, with clear information, warning, and error colours.
- Press `n` to read the complete notification. Scroll with `j`/`k`, then press Escape to return to the same card, revealed side, folds, and scroll position.
- Keep native notification timeouts, text entry, and custom review bindings intact. Expired notices cannot be reopened, and incoming notices do not replace the text you are reading.
- Simplify shared rendering and settings logic: 122 fewer application lines, with unchanged runtime dependencies.

## Update with uv

```bash
uv tool install --force "git+https://github.com/wh1skr/repetui.git@v0.2.3"
repetui --version
```

Restart Repetui after updating to use the new notification reader.
